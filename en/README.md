# SwapTeach 換你教

"SwapTeach: A Campus Skill-Exchange App" is the term project for Database Systems at Fu Jen Catholic University CSIE (academic year 115, semester 1, Prof. Shin-Hung Chang). It is also entered in the 2026 31st International ICT Innovative Services Awards.

**Current stage:** planning and documentation. No code yet.
