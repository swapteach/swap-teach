## AI 生成的 `.txt` 與官方投影片的矛盾

`Comprehensive Specification…txt` 看起來是 AI 依投影片產生的英文說明，有以下錯誤或沒有根據的內容：

1. **競賽選項錯誤。** `.txt` 把 ITSA 極客挑戰賽與 NCPC 輔大初賽列為滿足 15% 校外競賽的選項。官方投影片中，15% 的校外競賽是「資訊應用服務創新競賽」或「自行選擇校內外大型比賽」；ITSA 與 NCPC 是另外的**學期成績加分**。
2. **競賽類別不完整。** `.txt` 只列「大會專題類」與「國際交流類」，漏了「指定專題類」（教育AI組就屬於指定專題類）。
3. **遺漏重要規定。** `.txt` 沒有提到：競賽得分方式（未入決賽 5 分、入圍決賽 15 分、得獎專題滿分 40 分、前三名學期成績 99 分）、未使用 GitHub 扣 5 分、貢獻比例計分、沒製作沒報告整組 49 分、每週簽到。
4. **編造的內容。** `.txt` 對歷屆專題被打 X 的原因做了解釋（例如「流浪動物整合」只是公開 API 的包裝），投影片中只有名稱與 X 數，沒有這些理由。老師在第一堂課口頭說明了其中幾組的原因（見 [first-lecture.md](../docs/course/first-lecture.md#歷屆專題老師對-x-數的說明)），與 `.txt` 的說法不同；例如手搖達人，`.txt` 說是缺乏資料庫的複雜度，老師說的是「沒有用」。
5. **心得報告。** `.txt` 說心得報告是「嚴格必須」；投影片只寫「若有成果發表 → 心得報告」。
6. **無法確認的資訊。** `.txt` 提到張老師是 NCPC 輔大初賽的指導老師並附上 Email，投影片中沒有這些資訊。
