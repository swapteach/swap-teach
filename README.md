# 換你教 SwapTeach

> English version: [en/README.md](en/README.md)

「換你教－校園技能交換 App」是輔仁大學資工系「資料庫系統」（115 學年度第 1 學期，張信宏老師）的期末專題，同時參加「2026 第 31 屆大專校院資訊應用服務創新競賽」。

**目前階段：** 規劃與文件整理，尚未開始寫程式。

## 基本規則

- 所有文件以**繁體中文**為準。
- 直接 push 到 `main`，不需要開 Pull Request。
- 用 AI 編輯時，AI 會自動讀取 [AGENTS.md](AGENTS.md) 的規則；用網頁版 AI 時請看 [CONTRIBUTING.md](CONTRIBUTING.md)。
- 任務放在 GitHub Issues 與 Projects，標題中英並列。
